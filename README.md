# CashCafe — Astro Static Site

Coffee science, brewing, and cafe culture, built with Astro and deployed via GitHub Pages.

## Project Structure

```
/
├── public/                     # Static assets (favicon, CNAME, robots, og)
├── src/
│   ├── content/blog/           # Markdown articles (auto-generated + migrated)
│   ├── components/             # Astro components
│   ├── layouts/                # BaseLayout + ArticleLayout
│   ├── pages/                  # Routes (index, blog, categoria)
│   ├── styles/global.css       # Coffee palette design system
│   └── utils/                  # categories + dates helpers
├── scripts/                    # Python AI article generation
├── topics/                     # Topic JSON for AI generation
└── .github/workflows/          # Daily article cron
```

## Commands

- `npm install` — install deps
- `npm run dev` — local dev server
- `npm run build` — generate static site to `dist/`
- `npm run preview` — preview built site

## Deployment

Static output served from GitHub Pages (CNAME: cash-cafe.org).

`output: 'static'` in `astro.config.mjs`. Sitemap auto-generated by `@astrojs/sitemap`.
